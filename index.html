Lưu ý bảo mật: Gemini API Key là bí mật. Nếu lưu trực tiếp trong Realtime Database và Rules cho phép đọc công khai, bất kỳ ai cũng có thể lấy key. Bản này chỉ đọc/ghi key tại đường dẫn cấu hình bạn chỉ định; nên khóa Rules hoặc dùng Authentication/App Check.
Chưa nạp API Key.
Key và model được lưu tập trung tại app_settings/gemini và tự đồng bộ cho mọi máy dùng cùng Firebase.
Cơ chế mới: khi một máy lưu key, mọi máy khác dùng cùng Firebase sẽ tự tải key từ Realtime Database lúc mở ứng dụng hoặc khi dữ liệu thay đổi.
